# FixedItNow frontend

Next.js 16 (App Router, Cache Components, React Compiler), TypeScript,
Tailwind CSS v4, `lucide-react` icons.

```bash
npm install
npm run dev        # http://localhost:3000
npm run lint
npm run typecheck
npm test           # Vitest + Testing Library
npm run build
```

See the repository [README](../README.md) and [docs/](../docs).

> `AGENTS.md` is generated by Next.js and tells coding agents to read the
> bundled docs in `node_modules/next/dist/docs/`. Keep it.

## Structure

- `src/app/` routes, metadata, `robots`, `sitemap`, OG image
- `src/components/ui/` design-system primitives (Button, fields, Card, Badge, Dialog…)
- `src/components/layout/` header, footer, navigation
- `src/components/home/`, `professional/`, `services/` feature components
- `src/lib/` site config, presentation seed data, and data-access boundaries
- `src/app/globals.css` design tokens (`@theme`)
